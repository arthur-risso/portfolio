# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Primary: potential freelance clients (business owners, agencies) evaluating whether to hire Arthur for a web/UI project. They arrive from a link, skim, and decide whether to get in touch.

## Product Purpose

Personal portfolio of a web developer and UI/UX designer. Success means a freelance client understands what Arthur builds, trusts it works, and uses the contact section.

## Positioning

"Eu não decoro interfaces. Eu construo experiências que funcionam de verdade." The site proves this with working components instead of claims (e.g. the hero's real dark-mode switch: "isso é um componente de verdade, clica aí"). Performance and accessibility are presented as non-negotiable, not extras.

## Operating Context

Single-page site in Portuguese (pt-BR): Header, Hero, TechMarquee, About (with photo modal), Projects, Contact (form + copy email), Footer. Light and dark themes via a user toggle.

## Capabilities and Constraints

- React 19 + Vite + Tailwind v4, motion, Radix UI, embla-carousel, lucide-react.
- Projects section will show 2–3 strong projects.

## Evidence on Hand

- Each project has a live URL and a public GitHub repository (per the owner).
- No screenshots or videos exist yet.
- `src/data/projects.ts` still holds placeholder content; real titles, problems, and results must come from the owner. Do not invent clients, metrics, or outcomes.
- Profile photo: `public/pfp-portfolio.jpeg`.

## Product Principles

1. Prove, don't claim: show working things over adjectives.
2. Speak to the client's outcome, not only to the stack.
3. Few projects, told well, beat a long list.
